# Comment Graphic Prompt Templates

Use these when generating Myspace-era comment replies, reaction GIFs, and friend-wall drop-ins.

## Template A — Friendly Return Comment
```
Create a 2000s Myspace comment reaction GIF, transparent background, size {WIDTH}x{HEIGHT}.
Text: "{SHORT_PHRASE}".
Mood: supportive, bubbly, overexcited friend energy.
Visual ingredients: glitter text, pink glow outline, tiny hearts + stars, low-res crunch, 3-frame blink.
Substyle anchor: myspace_profile_bling.
Keep text readable at thumbnail scale.
Negative: modern flat UI, minimal design, clean vector branding, cinematic realism.
```

## Template B — Birthday / Event Shoutout
```
Generate a loud early-web shoutout badge for a profile comment section.
Headline text: "{NAME} {EVENT_PHRASE}".
Optional subtext: "xoxo" or "luv ya".
Use chrome/gel lettering, radial burst, glitter sweep every 0.9s, sticker icons (balloons/hearts/lips).
Colorway: hot pink + electric purple + white sparkle.
Compression artifacts and slight halo fringing are desirable.
Negative: contemporary typography, muted palette, soft minimal gradients.
```

## Template C — Light Drama Reaction
```
Produce a Myspace-style reaction stamp that says "{DRAMA_PHRASE}".
Tone: indirect drama, sarcastic but playful.
Visuals: dark background plate, neon text glow, skull/lips micro-icons, 2-frame flash alternation.
Keep composition compact for comment-thread posting.
Artifact targets: slight aliasing, crunchy gif dither, uneven outer glow.
Negative: polished social media ad style, high-end cinematic effects, clean sans-serif layout systems.
```

## Template D — Character Loop + Caption
```
Create a glitter GIF comment asset featuring {CHARACTER_TYPE} cutout.
Caption text: "{CAPTION}" in beveled script.
Animation: wink or blink loop, 4 frames max, loop around 1.2 seconds.
Add white stroke, pink halo, star twinkles, and one sticker corner embellishment.
Preserve early-web low-res charm and tacky luxury finish.
Negative: smooth interpolation, physically-correct lighting, minimalist aesthetics.
```
