# Prompt Formula (Long)

1. Declare substyle and output mode (asset vs full page).
2. Specify motif families and slogan behavior.
3. Specify palette with black-stage logic.
4. Specify material stack (glitter/chrome/gel/halo).
5. Add artifact constraints (low-res edges, compression bite, rough alpha).
6. Add composition/clutter instructions.
7. Add explicit anti-drift negatives.

Template:
`Create a [substyle] [output type] with [motifs], [text behavior], [palette], [effects], [artifact cues], [composition grammar]. Avoid [drift targets].`
