# Usage Modes

## Mode A: Prompt authoring
Use `10_prompt_system` + `11_drift_control` for direct generation.

## Mode B: Style QA
Use `11_drift_control/diagnostic_checklist.md` to evaluate outputs.

## Mode C: App integration
Use `13_structured_data` + `12_app_integration` for retrieval/controls.

## Mode D: Procedural graphics
Use `09_shader_and_genart_translation` for generator pipelines.
