# myspace_angelfire_graphics_style

A production-ready style system for **early-web glitter graphics**, split into two coordinated substyles:

- **Myspace profile bling** (identity performance, sticker assets, slogan badges)
- **Angelfire shrine chaos** (page-worldbuilding, tiled cosmos, widget ecology)

## Core stance
- Too much is often correct.
- Tackiness is intentional.
- Artifact-rich rendering is a requirement, not a defect.
- Cheap synthetic luxury (glitter, chrome, gel, halo) is central.

## How to use
1. Read `01_core_definition/` and `05_substyles/` to set direction.
2. Use `10_prompt_system/` for direct prompting.
3. Use `11_drift_control/` to diagnose failures.
4. Integrate `13_structured_data/` into tooling for retrieval, controls, and ranking.
