# Style Pillars

1. **Excess as grammar**: visual overload is structurally correct.
2. **Sincerity over irony**: emotionally direct slogans and symbols.
3. **Cheap luxury surfaces**: glitter/chrome/plastic halos.
4. **Artifact-positive rendering**: crunch, fringe, aliasing accepted.
5. **Webpage ecology**: assets must relate to page context.
6. **Substyle integrity**: self-performance (Myspace) vs worldbuilding (Angelfire).
