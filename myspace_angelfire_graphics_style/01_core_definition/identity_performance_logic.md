# Identity Performance Logic

## Myspace mode
Identity is presented as a decorated profile surface: badges, blinkies, glitter nameplates, attitude slogans.

## Angelfire mode
Identity is distributed across a full page ecosystem: shrine sections, fan devotion, cosmic/goth motifs, widget rituals.

## Rule
If composition centers on **self-brand stickers**, lean Myspace.
If it centers on **spatial shrine atmosphere**, lean Angelfire.
