# Cute / Trashy / Dark Spectrum

- **Cute**: bubblegum pinks, hearts, bunnies, princess text.
- **Trashy**: chrome gradients, rhinestone bursts, brat slogans, mall-kiosk glam.
- **Dark**: black stage, purple glow, skull/lip contrast, celestial goth filler.

Best outputs blend two poles while keeping tacky sincerity.
