# Style Definition

**Parent style:** early-web glitter graphics / profile bling / shrine-page chaos.

This style is built from decorative overstatement, emotional sincerity, and web-native artifact texture. It prioritizes symbolic immediacy (hearts, stars, crowns, skulls, lips, celestial icons), fake luxury surfaces (chrome, glitter, gel), and aggressive contrast staging (often black backgrounds with luminous overlays).

Two major substyles:
- **Myspace profile bling:** identity badge logic, comment-widget aesthetics, transparent cutout assets.
- **Angelfire shrine chaos:** page-world ecology, tiled wallpaper fields, devotional/cosmic clutter.
