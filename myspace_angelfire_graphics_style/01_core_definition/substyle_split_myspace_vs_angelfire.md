# Substyle Split: Myspace vs Angelfire

| Axis | Myspace Profile Bling | Angelfire Shrine Chaos |
|---|---|---|
| Main unit | Asset/sticker | Page/world |
| Typical canvas | Transparent PNG/GIF | Full HTML page environment |
| Text behavior | Slogans, names, attitude tags | Titles, shrine headers, navigation clutter |
| Layout | Clustered around profile blocks | Multi-column or stacked portal chaos |
| Risk | Generic social-media glitter | Generic goth/space wallpaper |
